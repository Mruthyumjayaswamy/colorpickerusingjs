# 🎨 Random Color Generator

A simple and fun **Random Color Generator** built using **HTML, CSS, and JavaScript**. With a single click, the app generates a random RGB color and applies it to the display box while showing the color code.

---

## 🚀 Features

- 🎲 Generate random RGB colors  
- 🖱️ One-click color generation  
- 🎨 Background updates dynamically  
- 🔤 Displays generated color code  
- 💡 Beginner-friendly project  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  

---

## 💡 How It Works

1. Click the **Generate Color** button  
2. A random RGB color is created using JavaScript  
3. The color is applied to the box background  
4. The color code is displayed on the screen  

---

## 📂 Project Setup

1. Download or clone the repository  
2. Open `index.html` in your browser  

No installation required 🚀
